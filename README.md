# Calculator Geometric (Java Swing)

A simple GUI-based Geometric Calculator built using Java Swing.  
This application allows users to calculate Area, Perimeter, and Volume of different shapes through an interactive interface.

## 🚀 Features
- Calculate Area of:
  - Square
  - Rectangle
  - Circle
  - Triangle
- Calculate Perimeter of:
  - Square
  - Rectangle
  - Circle
- Calculate Volume of:
  - Cube
  - Cylinder
  - Sphere
- User-friendly GUI using Java Swing
- Input validation with error handling

## 🖥️ Technologies Used
- Java
- Swing (GUI)

## 📂 How to Run
1. Clone the repository:
   git clone https://github.com/your-username/calculator-geometric.git

2. Navigate to the project folder:
   cd calculator-geometric

3. Compile the program:
   javac Calculator_Geometric.java

4. Run the program:
   java Calculator_Geometric

## 📸 Usage
- Enter values in the input fields.
- Click on Area, Perimeter, or Volume.
- Select the desired shape from the popup.
- View the result instantly.

## ⚠️ Notes
- Ensure valid numeric input.
- For circle and sphere, use radius as input.
- For cylinder, use radius (Number 1) and height (Number 2).
